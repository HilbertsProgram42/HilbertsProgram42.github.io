Checks

1 · First comparison with the ulam.ai exposition (21 Nov): the core of the analytic part agrees – same function G (ramp sum minus y log y − (1+γ)y), only an upper bound on windows [Y, Y3/2], same weights 1/(3o+1), same two-case window argument (complex pole via Cauchy estimates, real pole via positive residue), same residues, same constants (eD = 2, eL = 0, exponent 1/2 + 9ε). The ulam text stresses that positivity is a statement about residues, not about the function being nonnegative – we will make this explicit in the script. This was a summary-level comparison, not a line-by-line check.

2 · Section-by-section comparison with the ulam.ai exposition: in progress.

3 · Independent review of the delicate chapters against the manuscript (theta lifts and positivity, Selmer windows, final assembly and GRH): in progress.

Status of the Lean check (as reported, not re-run by us): the code was rebuilt independently on 20 Nov; the headline theorems depend only on the three standard axioms; some further replays were still pending at the time of the ulam.ai report. Formal acceptance by the mathematical community is pending.
